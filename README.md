# Utbygd vei og bane 2013–2025

Interaktiv oversikt over kilometer ny riksvei og jernbane åpnet for trafikk i Norge 2013–2025, fordelt på landsdel, utbygger og veitype, og på periodene 2014–2017, 2018–2021 og 2022–2025.

Kilde: Samferdselsdepartementets svar på spørsmål nr. 3935 til skriftlig besvarelse (5. oktober 2026).
